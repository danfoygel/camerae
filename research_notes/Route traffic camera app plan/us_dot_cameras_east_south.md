# US State DOT Traffic Camera Feeds — Eastern & Southern States

Method note: Besides web search, I sent live unauthenticated HTTP requests (curl) to public endpoints on **2026-11-18** to confirm formats, counts, CORS headers and whether streams are tokenized. No accounts were registered and no keys were used. Where a "source" below is an API URL, the finding comes from that direct request on that date. Camera counts are point-in-time snapshots. Endpoints marked "website-internal" are undocumented JSON calls that the public map pages make. They work today, but they are not an official API and their terms are unclear (see Licensing).

## Key Question 1: What is the camera inventory endpoint (URL, format), and does it include lat/lon, roadway, direction, milepost?

### Takeaway
Six of the target states (GA, FL, PA, CT, LA, NC) run the same IBI/Arcadis 511 platform. All six expose an identical keyed `/api/v2/get/cameras` JSON/XML endpoint with lat/lon, roadway and direction. Four states publish **keyless** public inventories with milepost or mile-marker data: Maryland CHART (JSON), Delaware (JSON), South Carolina (Iteris GeoJSON) and Kentucky (ArcGIS). Alabama ALGO also has a keyless JSON inventory. 511NY has moved off IBI to a Castle Rock CARS front end, and the old documented API path no longer returns data. NJ, MA, VA, TN, MS and DC have no keyless public inventory that I could confirm.

### Cited Findings
- **IBI 511 Cameras API (documented)**: endpoint `https://511la.org/api/v2/get/cameras`, params `key` (required) and `format` (`xml` or `json`, default json). Response fields: `Id`, `Source`, `SourceId`, `Roadway`, `Direction` (None, All Directions, Northbound, Eastbound, Southbound, Westbound, Inbound, Outbound, Both Directions), `Latitude`, `Longitude`, `Location`, `SortOrder`, `Views[]`. Each view has `Id`, `Url`, `Status`, `Description` and `VideoUrl`. The sample `VideoUrl` is an HLS `playlist.m3u8`. No milepost field. — [511LA GET Cameras doc](https://511la.org/help/endpoint/cameras)
- The same keyed endpoint exists on GA, FL, CT, LA and PA: an unkeyed call returned `400 <Error><Message>Invalid Key</Message></Error>` from each. — direct requests to [511ga.org/api/v2/get/cameras](https://511ga.org/api/v2/get/cameras?format=json), [fl511.com](https://fl511.com/api/v2/get/cameras?format=json), [ctroads.org](https://ctroads.org/api/v2/get/cameras?format=json), [511la.org](https://511la.org/api/v2/get/cameras?format=json), [511pa.com](https://www.511pa.com/api/v2/get/cameras?format=json)
- DriveNC (NC) is now on the IBI platform. Its developer doc lists a "Cameras — Returns all cameras" resource under the same key and throttle model. — [DriveNC API docs](https://www.drivenc.gov/developers/doc); [DriveNC Events endpoint doc](https://www.drivenc.gov/help/endpoint/event)
- NCDOT's legacy keyless API `eapps.ncdot.gov/services/traffic-prod/v1/cameras` now returns: "As of May 27, 2026, information about API data can be found at https://drivenc.gov/help/endpoint/event". — [NCDOT legacy endpoint](https://eapps.ncdot.gov/services/traffic-prod/v1/cameras)
- IBI sites also serve a website-internal DataTables endpoint, `/List/GetData/Cameras?query={...}&lang=en-US`, without a key. Its richer schema includes `images[].imageUrl`, `videoUrl`, `videoType`, `isVideoAuthRequired`, `refreshRateMs`, `roadway`, `direction`, `latLng.geography.wellKnownText` (WKT POINT), `source`, `region` and `county`. `recordsTotal` was GA 4,331; FL 4,978; PA 1,572; CT 347; LA 336; NC 1,022. — direct requests to [511ga.org](https://511ga.org/List/GetData/Cameras), [fl511.com](https://fl511.com/List/GetData/Cameras), [511pa.com](https://www.511pa.com/List/GetData/Cameras), [ctroads.org](https://ctroads.org/List/GetData/Cameras), [511la.org](https://511la.org/List/GetData/Cameras), [drivenc.gov](https://www.drivenc.gov/List/GetData/Cameras)

- **Mississippi**: `mdottraffic.com` describes itself as offering "Streaming Video for Mississippi Highways" and references `api.mdottraffic.com/prod/v3/login`, which suggests an authenticated API. — [MDOTtraffic](https://www.mdottraffic.com/landing.aspx)
- **New Jersey**: `511nj.org/api/v2/get/cameras` returned `401 {"error":"Something went Wrong"}` with CORS headers. I found no official developer page. — [511NJ](https://511nj.org/api/v2/get/cameras?format=json)

### Inferences
- An IBI client using `/api/v2/get/cameras?key=…` with Roadway/Direction/Lat/Lon/Views covers GA, FL, PA, CT, LA and NC (about 12,500 sites). It needs one developer key per state.
- Milepost data is available from MD (`milePost`), SC (`mrm`), KY (`milemarker`) and AL (`linearReference`), but not from the IBI API. For IBI states, route matching must use lat/lon plus roadway and direction.
- 511NY's move to CARS likely puts it on the same Castle Rock client family as other CARS states (outside this scope: e.g. MN, IA). That is unconfirmed for this region.

### Gaps
- I could not confirm whether the legacy 511NY `/api/getcameras` API is retired or moved, or what the new CARS `/cameras` endpoint needs (parameters, auth).
- Mass511, 511NJ, VDOT, TDOT and MDOT (MS) camera inventory endpoints were not confirmed.
- DC (DDOT) has no public feed. An HSEMA PDF camera list dated 2022-07-27 exists — [HSEMA](https://hsema.dc.gov/sites/default/files/dc/sites/hsema/Complete%20List%20of%20DDOT%20Cameras_7.27.2022.pdf).
- The I-95 Corridor Coalition / TETC was not researched in depth. I found no camera feed from it.

## Key Question 2: Is an API key or developer registration required, and what are the rate limits?

### Takeaway
All IBI-platform states require a free account plus a developer key, throttled at **10 calls per 60 seconds**. That is fine for a cached full-inventory pull but not for per-user queries. MD CHART, DelDOT, SC (Iteris CDN), KY (ArcGIS) and AL (ALGO v4) served inventories with no key. PennDOT and VDOT require a signed agreement. NCDOT's keyless API was retired in May 2026.

### Cited Findings
- 511GA: "Requires a developer key… Throttling is enabled. Ten calls every 60 seconds." A registered account is needed to request a key. — [511GA API docs](https://511ga.org/developers/doc)
- The same 10 calls/60 s note appears for CTroads, 511LA and DriveNC. — [CTroads API docs](https://ctroads.org/developers/doc); [511LA API docs](https://511la.org/developers/doc); [DriveNC API docs](https://www.drivenc.gov/developers/doc)
- 511NY (legacy): account, then developer opt-in, then approval email with key. Throttled at 10 calls/60 s. — [511NY developer help](https://511ny.org/developers/help)
- PennDOT: submit the Data Feed Request Form. No fee ("There is no charge for using PennDOT data feeds"), but streaming users must buy their own bandwidth. — [PennDOT data feeds](https://www.pa.gov/services/penndot/request-access-to-transportation-related-data-feeds)
- VDOT SmarterRoads: users must accept the usage agreement and create an account before subscribing to data sets. — [NASCIO award summary](https://nascio.org/awards-library/awards/vdots-smarterroads-data-portal); [CTB 2018 security brief](https://ctb.virginia.gov/media/ctb/agendas-and-meeting-minutes/2018/jan/tech/smarterroads_security_ctb_it_subcommittee_january_2018.pdf)
- VDOT is replacing or expanding SmarterRoads under a "NextGen" traffic operations data service. — [CTB Sept 2025 NextGen presentation](https://ctb.virginia.gov/media/ctb/agendas-and-meeting-minutes/2025/09/pres/next-generation-traffic-operations-data-service-nextgen-2025-09-10.pdf); [Route Fifty](https://route-fifty.com/infrastructure/2022/07/virginia-modernize-traffic-traveler-and-road-information-services/374676)
- TRANSCOM (NY/NJ/CT region) feeds need a registration separate from 511NY (2010 statement; may be outdated). — [nyc-dot-dev group](https://groups.google.com/g/nyc-dot-dev/c/p2ht5palwBg)
- MD CHART, DelDOT, SC GeoJSON, KYTC ArcGIS and ALGO v4 all returned full data with no key on 2026-11-18. ALGO sends `cache-control: max-age=95, public` on the inventory. — direct requests ([CHART](https://chartexp1.sha.maryland.gov/CHARTExportClientService/getCameraMapDataJSON.do), [DelDOT](https://tmc.deldot.gov/json/videocamera.json), [SC](https://sc.cdn.iteris-atis.com/geojson/icons/metadata/icons.cameras.geojson), [KY](https://services2.arcgis.com/CcI36Pduqd0OR4W9/ArcGIS/rest/services/trafficCamerasCur_Prd/FeatureServer/0/query?where=1%3D1&returnCountOnly=true&f=json), [ALGO](https://api.algotraffic.com/v4/Cameras))

### Inferences
- Architecture: a backend should pull each state's inventory on a schedule (e.g. hourly or daily) and serve route queries from its own spatial index. At 10 calls/min, live per-request calls to IBI states are not viable.
- Keyless endpoints have no published SLA and could add auth without notice. NCDOT's May 2026 cutover shows that this happens.

### Gaps
- No published rate limits were found for CHART, DelDOT, the SC CDN, KYTC ArcGIS (beyond ArcGIS Online defaults) or ALGO.
- The FL511 and 511PA developer-key process is not publicly documented (`/developers/doc` returns 404 on both).

## Key Question 3: What media is available (JPEG, MJPEG, HLS, RTSP)? Are streams tokenized? CORS? HTTPS?

### Takeaway
HLS (.m3u8) is the dominant format. **Untokenized HTTPS HLS with `Access-Control-Allow-Origin: *`** was verified for Maryland, Delaware, South Carolina (Skyline/skyvdn), Alabama (Wowza CDN) and Louisiana. These can play inline in a browser or app today. GA, FL, NC and CT mark video as auth-required, and GA and FL returned **401** without a session token. Every IBI state serves JPEG/PNG snapshots via `/map/Cctv/{imageId}` with CORS `*` and a 60-second cache. Those snapshots are the most portable fallback. Kentucky is snapshot-only. PennDOT video is licensed only.

### Cited Findings
- **MD CHART HLS**: `https://strmr5.sha.maryland.gov/rtplive/{cameraId}/playlist.m3u8` returned 200 `application/vnd.apple.mpegurl` with `access-control-allow-origin: *` and HSTS. The streaming host comes from the `cctvIp` field (strmr3/strmr5/strmr10). — [CHART HLS sample](https://strmr5.sha.maryland.gov/rtplive/7a00a1dc01250075004d823633235daa/playlist.m3u8); [CHART JSON](https://chartexp1.sha.maryland.gov/CHARTExportClientService/getCameraMapDataJSON.do)
- **DelDOT**: `https://video.deldot.gov/live/{id}.stream/playlist.m3u8` returned 200 with ACAO `*`. The JSON also lists http:1935 HLS, RTMP, F4M and Smooth Streaming URLs (legacy). — [DelDOT HLS sample](https://video.deldot.gov/live/KCAM001.stream/playlist.m3u8)

- **Kentucky**: the `snapshot` field holds JPEG URLs, e.g. `https://www.trimarc.org/images/milestone/CCTV_05_71_0103.jpg`. Some rows are Indiana TrafficWise images over plain `http://pws.trafficwise.org/...`. — [KYTC ArcGIS](https://services2.arcgis.com/CcI36Pduqd0OR4W9/ArcGIS/rest/services/trafficCamerasCur_Prd/FeatureServer/0/query?where=state%3D%27Kentucky%27&outFields=*&resultRecordCount=1&f=geojson)
- **Tennessee**: TDOT's feeds are hosted by Skyline Technology Solutions. Skyline cut off a third party (SafetyVid) for downloading too much video. TDOT counsel said constant downloads "could risk shutting the feeds down". — [Knox News via Yahoo](https://www.yahoo.com/news/private-companies-clash-over-tdot-090551143.html)
- **Virginia**: the 511 site shows "PLEASE NOTE: VDOT cameras are intended to provide real-time traffic information. VDOT does not record traffic camera footage." — [511 Virginia app bundle](https://511.vdot.virginia.gov/)

### Inferences
- Skyline (skyvdn) hosts video for SC (open), GA (tokenized) and TN. Whether a Skyline stream is tokenized depends on each state's configuration.
- For auth-required IBI states, the website presumably fetches a short-lived token through an internal call. Replicating that would likely breach site terms. Use the snapshot URL instead, or request official video access.
- Plan for mixed transport in the player: HLS (TS and fMP4), DASH (AL), and JPEG polling at 10–60 s.

### Gaps
- I did not determine the token mechanism or lifetime for GA, FL or NC HLS.
- I did not verify snapshot refresh intervals beyond cache headers.
- MJPEG was not observed anywhere.
- TN, VA, MS, NJ and MA stream formats were not verified.

## Key Question 4: Licensing and terms of use (redistribution, embedding, attribution, data-sharing agreements)

### Takeaway
Terms are the main constraint. PennDOT (video license plus required attribution), VDOT (SmarterRoads agreement), 511NY (Developer's Access Agreement), MassDOT (Developer's License Agreement) and TDOT (access at TDOT's discretion) all use formal agreements. CTroads' site terms limit use to individuals seeking traveler information, which argues against scraping its internal endpoints. MD CHART's data feed page states no terms. No document I found explicitly allows re-streaming video. Every agreement reserves the right to cut access without notice.

### Cited Findings
- PennDOT: data feed use is governed by PennDOT's Terms and Conditions for Use. Camera streams are governed by a "Non-Exclusive Video Sharing License Agreement" provided after the request. Users "are required to acknowledge PennDOT as the source of data", and logo use guidance is given after approval. — [PennDOT data feeds](https://www.pa.gov/services/penndot/request-access-to-transportation-related-data-feeds)
- 511NY: API use is governed by a Developer's Access Agreement. — [511NY DAA](https://511ny.org/developers/daa) (now redirects into the new SPA; current text not verified)
- MassDOT: "Any use of the data provided acknowledges acceptance of MassDOT's Developer's License Agreement". The 2009 agreement reserves the right to suspend or terminate the data at any time without notice. — [MassDOT Highway data for developers](https://www.mass.gov/info-details/highway-data-for-developers); [MassDOT Developer's License Agreement (2009)](https://www.mass.gov/doc/developers-license-agreement-11132009/download)
- CTroads Terms and Conditions: the site "may be used only for a lawful and appropriate purpose by individuals seeking consumer traveler info". Users may not decompile or reverse engineer the software. Misuse "may result in your IP address being permanently blocked". — [CTroads Terms](https://ctroads.org/termsandconditions)
- VDOT: an older ITS architecture agreement says VDOT keeps the right to terminate any video feed if cameras capture images inappropriate for public dissemination. — [VDOT/TDOT ITS architecture agreement (Kimley-Horn)](https://extsites.kimley-horn.com/projects/TennesseeITSArchitecture/documents/bristol/InteractiveITSArchitecture/web/html/agree/agr7.htm)
- TDOT: activating and terminating access is "exclusively at the discretion of TDOT personnel", and TDOT does not guarantee continuity. TDOT's private-user agreement says it does not record video and provides no recordings. — [FHWA appendix](https://ops.fhwa.dot.gov/publications/fhwahop19037/appa.htm); [TDOT Data Sharing (Public-Private)](https://extsites.kimley-horn.com/projects/TennesseeITSArchitecture/interactiveITS/web/html/agree/agr2.html)
- MD CHART: the data feeds page lists the camera feed with no terms, registration or video-use restrictions stated. — [CHART Data Feeds](https://chart.maryland.gov/DataFeeds/GetDataFeeds)

### Inferences
- Lowest-risk path: use the documented keyed APIs (IBI states, under each state's developer agreement) and the officially published keyless feeds (MD CHART, DelDOT JSON). Show "Source: [State DOT]" attribution in the UI and play streams directly from the DOT's servers rather than re-hosting them.
- The `/List/GetData/Cameras` endpoints, the SC Iteris CDN GeoJSON and the ALGO v4 API are website backends, not documented public APIs. Get written permission from those DOTs before relying on them in production.
- Heavy polling can get access cut off, as the TN/Skyline case shows. Cache inventories and fetch media only when a user is viewing.

### Gaps
- I could not retrieve the full text of the IBI developer agreements (GA, FL, LA, NC), the VDOT SmarterRoads agreement, the 511NY DAA, or the FL511, SCDOT, KYTC, ALDOT, DelDOT and MDOT terms on embedding or hot-linking.
- The PennDOT video license PDF contents were not read.

## Key Question 5: Shared vendor platforms and third-party (TrafficLand etc.) video licensing

### Takeaway
**IBI/Arcadis 511**: GA, FL, PA, CT, LA, NC (and formerly NY). One client covers these with per-state keys. **Castle Rock CARS**: NY's new 511 front end. **Iteris ATIS**: SC (public GeoJSON). **Skyline/skyvdn** hosts video for SC, GA and TN. **TrafficLand** supplies CT camera images and historically hosted Northern Virginia video. In-house systems: MD CHART, DelDOT, AL ALGO, KY ArcGIS, MS MDOTtraffic.

### Cited Findings
- The IBI page structure, `/api/v2/get/cameras`, `/List/GetData/Cameras` and `/map/Cctv/{id}` are identical across 511ga.org, fl511.com, 511pa.com, ctroads.org, 511la.org and drivenc.gov. CTroads list records show `lastEditedBy` @ibigroup.com. — [CTroads list](https://ctroads.org/List/GetData/Cameras); [511GA docs](https://511ga.org/developers/doc)
- IBI built the original 511NY system. — [IBI Group: New York 511 launches](https://ibigroup.com/?p=14579). The current front end uses Castle Rock CARS services on `*.carsprogram.org`. — [511NY config](https://demo.511ny.org/configs/main.json?v=1.10.0)
- SC 511 runs on Iteris ATIS (`aggregator.iteris-atis.com`, `sc.cdn.iteris-atis.com`) with Skyline skyvdn video. — [511SC](https://www.511sc.org/); [SC GeoJSON](https://sc.cdn.iteris-atis.com/geojson/icons/metadata/icons.cameras.geojson)
- GA camera records list source "SKYLINE". FL lists "DIVAS-District N" (FDOT's DIVAS video system). NC lists "IVDs-Division N". LA lists "LADOTD". — [511GA](https://511ga.org/List/GetData/Cameras); [FL511](https://fl511.com/List/GetData/Cameras); [DriveNC](https://www.drivenc.gov/List/GetData/Cameras); [511LA](https://511la.org/List/GetData/Cameras)
- CT camera records list `source: "TRAFFICLAND"`. — [CTroads list](https://ctroads.org/List/GetData/Cameras)
- TrafficLand hosts video from VDOT's Northern Virginia cameras and distributes it to subscribing agencies. A VDOT agreement with TrafficLand covers a Statewide Video Distribution System allowing up to three private vendors. — [Roads & Bridges](https://www.roadsbridges.com/vdot-expands-video-service); [VDOT ITS architecture agreement](https://local.iteris.com/virginiaitsarchitecture/architectures/d9/html/agreements/agreement17.html)
- DC: TrafficLand historically carried DDOT views (112 DC views, 415 regional, 2000s). DDOT currently shares CCTV with HSEMA, with no public feed. — [GovTech](https://www.govtech.com/public-safety/Traffic-Web-Site-Adds-54-Live.html); [Nextgov 2003](https://nextgov.com/digital-government/2003/12/web-cams-installed-for-dc-traffic/224861); [DDOT Open Government](https://ddot.dc.gov/page/open-government-and-foia-ddot)
- TDOT video is hosted by Skyline Technology Solutions. — [Knox News via Yahoo](https://www.yahoo.com/news/private-companies-clash-over-tdot-090551143.html)

### Inferences
- Build order: (1) an IBI adapter for 6 states (~12.5k sites); (2) bespoke adapters for MD, DE, SC, AL and KY, each a small keyless JSON/GeoJSON/ArcGIS parser; (3) CARS (NY) after its API is clarified.
- TrafficLand-backed cameras (CT, NoVA, possibly DC) are most likely to need commercial licensing for video. Snapshots via the 511 site may be the only free option.

### Gaps
- Mass511, 511NJ, 511VA and SmartWay vendors are not confirmed.
- Current TrafficLand coverage of DC and VA in 2026 is not confirmed.
- The ALGO `/drm/` stream path suggests some protected streams. Not investigated.
